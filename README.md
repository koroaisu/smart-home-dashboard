# Smart Home Dashboard

Node.jsで動くローカル専用の試作。依存パッケージ・有料API・認証情報は不要です。

## 起動

Windowsでは `start.cmd` をダブルクリック。ターミナルでは `node server.mjs`。http://127.0.0.1:5173/ を開きます。終了はCtrl+C。既存サーバーではページを再読み込みしてください。

## 画面

横スワイプ・横スクロール・下部のアイコンタブでホーム／家電操作／エンタメ／ニュース／カレンダーを切り替えます。画面領域へフォーカスして左右キーでも移動できます。

- ホーム：左に場所・日付・時計・予定・天気・最高最低気温・AQI・PM2.5・花粉・日の出入り。中央にセクメト、右に室温・湿度・CO₂と機器状態。
- 家電操作：照明・掃除機のデモ操作。
- エンタメ：このWindows PCの再生アプリ名・曲名・アーティスト・再生状態を表示。画面表示中に約10秒ごとに更新。再生操作は行いません。
- ニュース：架空サンプルカードと分類切り替え。実記事・最新ニュースではありません。
- カレンダー：月送り、日付選択、日付付き予定の追加・完了・確認付き削除。

照明設定と予定はこのブラウザのlocalStorageに保存。外部・別端末には同期しません。日付のなかった旧予定は読み込み時の今日へ割り当て、新形式での保存後は日付を保持します。ホームは今日の予定のみ表示します。

天気・環境値・家電はデモ。CO₂は680 ppmの固定サンプルで、センサーには未接続です。AI会話・マイク入力・実機API・カレンダー同期・PWA・公開は未実装です。

## PCの音楽情報

サーバーを起動し直すと `/api/media` が利用できます。WindowsのGlobalSystemMediaTransportControlsSessionManagerを読み取ります。アカウントへのログインや認証キーは不要。メディアセッション非対応アプリや別端末の再生は取得できません。ブラウザ経由はブラウザ名を表示し、音楽サービスを推測しません。複数再生中の場合はWindowsの現在セッションを優先し、現在セッションが停止中なら再生中のセッションを選びます。端末の既定セッションであり音楽以外のメディアも含まれることがあります。

読み取り失敗・タイムアウト・サーバー未再起動では古い曲を表示し続けず、取得できない状態を表示。情報はメモリ内で8秒キャッシュし、外部送信・localStorage保存はしません。APIは127.0.0.1の同一オリジン向けに限定。

2026-11-08検証：Nodeテスト計6件成功。Windows API呼び出し成功、現環境ではidle（取得可能なセッションなし）。Apple Music・Amazon Musicの実際の再生中表示と更新後の画面は未検証。サンドボックス内では取得不可、通常のWindowsユーザー環境での起動が必要。

公式資料：https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmanager
