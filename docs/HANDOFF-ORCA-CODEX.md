## 見た目の確定した方針

- レトロゲーム風。NES.cssの枠・吹き出し、DotGothic16、クリーム・砂色・茶色を基調。
- セクメトのピクセル絵は中央。囲う大きな枠は付けない。
- **家電アイコンだけカラー、それ以外はモノクロ。** 最新の参考画像にカラーの天気などがあっても、この明示方針を維持している。
- 余計な説明文や「おかえりなさい」は不要。数値はモックのままでよく、モックという注意書きは画面に出さない。
- 下部タブはアイコン中心で文字を減らす。ホーム／家電操作／エンタメ／ニュース／カレンダー／通知の6ページ。スワイプでも移動。
- ヘッダー・フッターを固定し、枠の表示領域を各ページでそろえる。増える情報は枠の内部でスクロール。室内環境は固定項目なのでスクロールさせない。
- 固定4:3は撤回済み。iPad Air第5世代を含む実際の画面比に自動追従する。
- テレビ接続はやめた。音楽サービス／再生元を表示する方向。

## 現在の画面構成

### ホーム

- 左上ヘッダー：位置情報。右上：全画面ボタン。
- 左列：屋外環境 → 予定 → 室内環境。
- 屋外環境は上から**PM2.5、AQI、花粉**。室内環境とそろえた行表示。
- 室内環境：温度、湿度、CO₂と「快適」「良好」等。快適とON/OFFは暗い文字＋背景で読みやすく調整済み。
- 中央：日付・時計、天気と「気温」、最高／最低の統合表記、その下に吹き出しとセクメト。日の出・日の入りは削除済み。
- 「セクメト」の名前は吹き出し左上に重なるNES.cssの小さな枠。
- 右列は家電状態のみ。左右列幅は各224論理pxで同幅。家電を押すと詳細操作の小窓。

### 家電

エアコン、フロアランプ、天井照明、加湿器、サーキュレーター、空気清浄機、ロボット掃除機。現在はローカル状態のデモで、実機連携は未実装。電源状態でアイコンもON/OFFに切替。

### 吹き出しと通知

未読が2件以上なら「通知がN件あります。」を優先。それ以外はこれまでのひとこと・予定案内を話す。通知ページで蓄積履歴を確認できる。

**通知の吹き出しは押しても何も起きない。予定の吹き出しのみカレンダーへ遷移。** 通知一般をタップ可能に戻さない。

### エンタメ

ピクセル風の回るレコードと針。中心にジャケット写真、写真がなければSEKHMET / 33 RPMのラベル。再生中のみ回転し、一時停止で角度を維持。再生時間・進捗バー・前／再生／次ボタンがある。

`/api/media`からWindows PCのGSMTC再生情報を読み取り、取得できた再生元を表示する。Apple Music/Amazon Music等の契約アカウント連携ではない。**再生操作APIは未実装で、操作ボタンは無効。** ホスト公開版からPCの情報は読めない。

### その他

ニュースは仮の3記事。カレンダーは月表示を広く、右の予定欄を狭くし、年月見出しを大きくした。予定追加ダイアログもレトロ枠で統一。

## 最新レビューで分かった未解決事項

優先順位は提案。実装はまだ変更していない。

1. **狭幅の全体縮小**：fitViewportはmin(1,width/1024,height/768)で縮小。320×740ではscale=0.3125、44pxボタンが表示上13.75px。狭幅で再配置する必要がある。iPad横1180×820では44pxを維持。
2. **見えないページへのフォーカス**：ホームの掃除機詳細からTabすると、画面外の家電操作スイッチへ移る。各ページにinert等の切替がない。非表示ページをキーボード・読み上げ対象から外す候補。
3. **通知が途中値で埋まる**：range inputごとにsave→syncNotifications。既存履歴に同一分の大量の温度値、同値3件も確認。値表示は即時、通知はchange等の操作確定時に集約したい。
4. サーキュレーターの名前が途中で折り返す。右枠を単純に広げず、名前・状態バッジの内側配置を改善する候補。
5. 家電アイコンが表示上16pxで小さい。原寸16×16は維持し、UIだけ32×32の整数倍率にする候補。
6. メディア空状態で「このPCの再生情報」が重複。無効な再生操作の理由も分からない。短い状態表示へ改善する候補。
