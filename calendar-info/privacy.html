Sekhmet Calendar

プライバシーポリシー

本ポリシーは、個人用ホームダッシュボードのGoogleカレンダー連携機能「Sekhmet Calendar」（以下「本アプリ」）に適用されます。

1. アクセスする情報と利用目的

利用者の同意に基づき、Google Calendar APIからカレンダー一覧と、選択したカレンダーの予定情報を取得します。カレンダー名・識別子・色、予定の識別子・タイトル・開始日時・終了日時・終日区分などを、予定の選択、表示、重複の除去、自動更新に利用します。

要求する権限は、カレンダー一覧と予定の読み取り専用です。Googleカレンダーの予定を作成・変更・削除しません。

2. 保存と保護

取得した予定は、処理中のサーバーメモリと、画面を開いているブラウザのメモリで扱います。本アプリはGoogleの予定をデータベースやブラウザのlocalStorageへ保存しません。表示対象のカレンダー識別子と、利用者が手動で追加した端末内予定はブラウザのlocalStorageに保存されます。

Googleとの接続に使うアクセストークンと更新用トークンは、暗号化したHttpOnly・Secure Cookieとして利用端末に保存し、Cloudflare上のサーバー処理で使用します。ブラウザのJavaScriptにはトークンを返しません。暗号鍵とクライアントシークレットはサーバー側のSecretsで管理します。

接続Cookieは、予定を正常に取得するたびに有効期間が更新され、最後の正常取得から最大30日間保持されます。Google側の許可失効やログイン期限により、それ以前に再接続が必要になる場合もあります。

3. 外部サービスと共有

本アプリはGoogleの認証・カレンダーAPIと、Cloudflareの配信・サーバー処理・アクセス認証を利用します。これらのサービスは通信と認証に必要な情報を処理します。Googleの予定データを広告、販売、第三者のAIモデルの学習に利用せず、予定表示に必要な処理以外の目的で第三者へ提供しません。

Google APIから受け取る情報の利用は、Google API Services User Data PolicyのLimited Use要件に従います。外部サービスの取り扱いは、GoogleのプライバシーポリシーとCloudflareのプライバシーポリシーもご確認ください。

4. 連携の解除とデータの削除

ダッシュボードの「カレンダー → 接続設定」から連携を解除できます。本アプリはGoogleに許可の取り消しを要求し、接続Cookieと表示中のGoogle予定を消去します。通信障害などでGoogle側の取り消しが完了しない場合は、Googleアカウントのサードパーティとの接続から本アプリのアクセス権を取り消してください。

端末内の手動予定や設定はGoogle連携の解除だけでは消去されません。不要な場合はブラウザの当該サイトのデータを消去してください。Googleカレンダー本体の予定は変更・削除されません。

運営者は本アプリの所有者個人です。お問い合わせはGoogleの同意画面に表示されるユーザーサポートメールアドレスへお寄せください。機能やデータの取り扱いを変更した場合は、本ページの内容と更新日を改訂します。
